# راهنمای تصاویر World Eldoria

تمام تصاویر سفارشی این پروژه باید واقعاً JPEG باشند و پسوند `.jpg` داشته باشند. صرفاً تغییر نام پسوند فایل کافی نیست؛ فایل‌های PNG/WebP را قبل از استفاده به JPG تبدیل کنید.

## پوشه‌ها
- `boss/`: تصاویر ۵۰ باس؛ نام‌ها مطابق README همان پوشه
- `dungeon/`: دانجن‌ها
- `adventure/`: مناطق ماجراجویی
- `menu/`: پنل‌های اصلی
- `characters/`: شخصیت و پروفایل پیش‌فرض
- `monsters/`: هیولاهای عادی
- `skills/`: عناصر و مهارت‌ها
- `combat/`: صحنه‌های نبرد
- `quests/`, `party/`, `guild/`, `pvp/`, `ranking/`, `shop/`, `fan_art/`, `settings/`, `admin/`, `ui/`: بخش‌های متناظر
- آیتم‌ها عمداً خارج از این ساختار کلی باقی می‌مانند و پوشه‌های فعلی `items/`, `equipment/`, `materials/` حفظ شده‌اند.

## آپلود
هر عکس را با نام دقیق فهرست README در پوشهٔ مربوط قرار دهید. برای تحویل، پوشهٔ `assets/` را ZIP کنید. تصاویر اختصاصی که هنوز موجود نیستند به‌صورت فایل خالی ساخته نشده‌اند؛ README فقط فهرست نام‌های موردنیاز است.
